Это **учебный проект** для изучения и практики основ веб-разработки.

**Цель проекта:**
- Минималистичные веб-часы (отображение текущего времени с точностью до секунд)
- Практика ванильного JavaScript, HTML5, Tailwind CSS
- Изучение Git workflow (GitHub Flow, Conventional Commits, PR descriptions)
- Практика адаптивного дизайна для мобильных устройств

**Как применить:**
- Решения должны быть простыми и образовательными
- Фокус на best practices: правильные коммиты, структурированные PR, responsive design
- Не нужна сложная архитектура или избыточные улучшения
- Предлагай улучшения, которые обучают или демонстрируют хорошие практики
