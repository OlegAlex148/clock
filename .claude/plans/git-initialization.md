# План инициализации Git репозитория

## Контекст
Проект "web-clock" — минималистичный веб-часы на ванильном JavaScript и HTML5. Сейчас это не git репозиторий. Инициализация позволит отслеживать изменения, сохранять историю и упростит будущее сотрудничество и развертывание.

## Подход

### 1. Инициализировать репозиторий
- [x] Выполнено

```bash
git init
```
Создаст скрытую папку `.git` для отслеживания истории.

**Результат:** Репозиторий инициализирован в `/Users/oleg/Documents/web/clock/.git/`

### 2. Создать `.gitignore`
- [x] Выполнено

Создать файл `.gitignore` с исключением:
```
# Временные файлы и кэш
.DS_Store
.idea/
.vscode/
*.log
node_modules/
dist/
```

**Результат:** Файл `.gitignore` создан в корне проекта

Этот проект не требует node_modules (нет зависимостей), но файл пригодится для будущых расширений.
