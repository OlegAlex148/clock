# Web Clock

Минималистичные веб-часы, отображающие текущее время с точностью до секунд. Проект использует ванильный JavaScript, HTML5 и Tailwind CSS.

## Описание

Приложение выводит:
- **Время** в формате `HH:MM:SS` (обновляется каждую секунду)
- **Дату** в формате российской локали (например, "7 августа 2026 г.")
- **Год** текущий

Время синхронизируется с системными часами.

| Технология | Назначение |

| **HTML5** | Структура страницы |
| **JavaScript (Vanilla)** | Логика обновления времени |
| **Tailwind CSS** | Стилизация (CDN) |

- Без зависимостей
- Без фреймворков

### Файлы проекта

- **`index.html`** — HTML разметка с встроенными стилями Tailwind, элементы для отображения времени (#clock), даты (#date) и года (#year)
- **`script.js`** — Функция `updateClock()` для обновления отображения времени и даты, вызывается каждую секунду через `setInterval()`

## Развёртывание и запуск

### Локальная разработка

Используйте встроенный HTTP сервер Python:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере: **http://localhost:8000**

Или откройте файл непосредственно:
```bash
open index.html
```

## Архитектурные решения

- **Monospaced шрифт** (`font-mono`) — предотвращает сдвиги ширины при смене цифр
- **`padStart(2, '0')`** — обеспечивает нулевое заполнение для одноразрядных часов, минут, секунд
- **`setInterval(1000)`** — обновляет часы каждую секунду
- **Tailwind CDN** — упрощает без необходимости в шаге сборки
