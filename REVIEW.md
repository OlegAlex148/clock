# Code Review Checklist

## PR Description
- [ ] PR содержит раздел **Summary** с описанием изменений
- [ ] Указаны шаги для тестирования в разделе **Testing**
- [ ] Если применимо, указаны связанные issues в **Related Issues**
- [ ] Добавлены дополнительные примечания в **Notes** (если необходимо)

## Commits
- [ ] Используется формат Conventional Commits: `<type>(<scope>): <subject>`
- [ ] Коммиты атомарные и сосредоточены на одном логическом изменении
- [ ] Тип коммита корректен: `feat`, `fix`, `style`, `refactor`, `docs`, `chore`
- [ ] Область (scope) релевантна (если используется)

## Ветвление и Git
- [ ] Ветка создана от `master` и имеет правильное имя:
  - `feat/<feature-name>` для новых функций
  - `fix/<issue-name>` для исправлений
  - `docs/<doc-name>` для документации
  - `refactor/<area>` для рефакторинга

## Код
- [ ] Код следует архитектурным нотам проекта
- [ ] Используется ванильный JS без фреймворков
- [ ] Для часов используется `setInterval(1000)` для обновления каждую секунду
- [ ] Применяется `padStart(2, '0')` для нулевого заполнения времени
- [ ] Используется моноширинный шрифт (`font-mono`) для часов

## Стиль
- [ ] HTML структура логична и семантична
- [ ] Tailwind CSS классы используются из CDN (без build шага)
- [ ] Нет хардкода; используются переменные и константы где уместно
- [ ] Код отформатирован согласно стилю проекта

## Тестирование
- [ ] Часы отображают время в формате `HH:MM:SS`
- [ ] Секунды обновляются каждую 1 секунду
- [ ] Дисплей центрирован на странице
- [ ] Типография читаемая
- [ ] Проверено на разных браузерах/устройствах (для UI изменений)

## Функциональность
- [ ] Изменения работают согласно описанию PR
- [ ] Нет регрессий в существующем функционале
- [ ] Edge cases обработаны корректно
